# AI-NDT Vision — UI/UX Direction

The supplied reference is the visual direction: premium industrial SaaS, dark navy/black surfaces,
restrained cyan accents, large inspection imagery, thin borders, glass analysis overlays and strong
typographic hierarchy.

## Product hierarchy

Primary workflow:
Project → Inspection → AI Analysis → Review → Evidence → Report

Primary authenticated navigation:
Overview · Projects · Inspections · Drive · Analytics

Batch, Compare, Model and About remain available through contextual links/routes where needed, but
they are not primary navigation destinations. This prevents the application from feeling like a
collection of unrelated features.

## UX rules

- One primary action per screen.
- Project context is always visible when working with inspection data.
- Prefer tables, evidence panels and actionable summaries over decorative KPI walls.
- Storage is presented as Project Drive, not a generic file manager.
- AI results must be clearly labeled preliminary/reviewable.
- Use imagery to explain inspection work, not as decoration alone.
